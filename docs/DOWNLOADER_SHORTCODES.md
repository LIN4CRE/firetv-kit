# Fire TV Downloader Shortcodes & Direct URLs

If you ever need to set up a brand-new Fire TV from scratch using **only the Fire TV remote control** (zero PC and zero USB drive needed):

---

## Step 1: Install the "Downloader" App
1. From the Fire TV Home Screen, go to **Find** -> **Search**.
2. Type **Downloader** and install the orange app by *AFTVnews*.

---

## Step 2: Enable "Install Unknown Apps"
1. Go to **Settings** (gear icon) -> **My Fire TV** -> **Developer Options**.
   > *Note:* If Developer Options is hidden on newer Fire OS versions, go to **Settings** -> **My Fire TV** -> **About**, highlight the Fire TV device name, and press the **Select button 7 times rapidly** until a message says *"No need, you are already a developer."*
2. Select **Install unknown apps**.
3. Highlight **Downloader** and turn it **ON**.

---

## Step 3: Enter Downloader Shortcodes

Open **Downloader** and enter any of the following 5-digit shortcodes into the URL field:

| App | Downloader Code | Direct Web URL |
| :--- | :--- | :--- |
| **SmartTube** (Ad-free YouTube & SponsorBlock) | `28544` | [smarttubeapp.github.io](https://smarttubeapp.github.io) |
| **Stremio** (Android TV Edition) | `81044` | [stremio.com/downloads](https://www.stremio.com/downloads) |
| **TiviMate** (IPTV Player) | `272483` | [tivimate.com/tivimate.apk](https://tivimate.com/tivimate.apk) |

---

## Step 4: Configure Stremio Settings via Remote

After opening Stremio and signing in:
1. Navigate down the left sidebar to **Settings** (gear icon).
2. Under **Playback**:
   * **Hardware-accelerated decoding:** `ON`
   * **Frame rate matching:** `Disabled`
   * **Tunnelled playback:** `OFF`
3. Under **Server**:
   * **Torrent Profile:** `Ultra Fast`
4. Back out to the catalog. Enjoy instant, buffer-free playback with zero decoder lockups!
